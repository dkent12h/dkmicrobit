마이크로비트 펌웨어

연결된 마이크로비트의 펌웨어 버전을 확인하고, 업데이트까지 차근차근 안내합니다.

방법 A. USB로 바로 연결해서 보기

마이크로비트를 USB로 연결한 뒤 버튼을 누르고, 목록에서 “DAPLink CMSIS-DAP”을 선택하세요. 보드 종류(V1/V2)를 알려줍니다. (크롬·엣지 필요, 링크 화면에서는 막힘)

방법 B. DETAILS.TXT로 정확한 버전 보기 권장

MICROBIT 드라이브 안의 DETAILS.TXT 파일을 아래에 끌어다 놓거나 선택하세요. 펌웨어(Interface) 버전은 이 파일에 들어 있습니다.

여기에 DETAILS.TXT 파일을 끌어다 놓기
파일 내용을 직접 붙여넣기

최신 버전 기준표

공식 안내(microbit.org) 기준값입니다. 새 버전이 나오면 아래 숫자를 직접 고치세요. 이 브라우저에 저장됩니다.

보드최신 Interface 버전
micro:bit V1 (ID 9900·9901)
micro:bit V2 (ID 9903·9904 등)
공식 펌웨어 페이지에서 최신 버전 확인 ↗

업데이트 순서

작업이 끝난 단계는 자동으로 체크됩니다. 업데이트 중에는 USB를 뽑지 마세요.

  1. 펌웨어 파일(.hex) 내려받기
    보드에 맞는 파일을 받습니다. V2는 V2.00과 V2.20/2.21 두 종류가 있으니 보드 뒷면 오른쪽 아래 표기를 확인하세요.
    공식 펌웨어 페이지 열기 ↗
  2. 받은 .hex 파일 불러오기
    .hex 파일을 여기에 끌어다 놓기
  3. MAINTENANCE 모드로 만들기
    USB 케이블과 배터리를 모두 뽑습니다 → 보드 뒷면의 리셋 버튼을 누른 채로 USB를 컴퓨터에 연결합니다 → 컴퓨터에 MAINTENANCE 드라이브가 나타나면 버튼에서 손을 뗍니다.
  4. MAINTENANCE 드라이브로 복사
    아래 버튼을 누르면 저장 창이 열립니다. MAINTENANCE 드라이브를 고르고 저장하세요. (파일 탐색기에서 .hex를 직접 끌어다 놓아도 됩니다.)
  5. 다시 확인하기
    보드 뒷면의 노란 불이 깜빡임을 멈추고 MICROBIT 드라이브가 다시 나타나면 완료입니다. ‘① 버전 확인’에서 DETAILS.TXT를 다시 열어 버전이 올라갔는지 확인하세요.

문제가 생겼을 때

MAINTENANCE 드라이브가 안 보여요

케이블이 충전 전용이 아닌지 확인하고, 다른 USB 포트로 바꿔 보세요. 리셋 버튼을 꽉 누른 채로 연결해야 합니다.

복사 후 FAIL.TXT가 생겼어요

보드 종류와 맞지 않는 파일일 가능성이 큽니다. V2.00과 V2.20/2.21 파일을 바꿔서 다시 시도하세요.

브라우저에서 저장 창이 안 열려요

크롬 또는 엣지를 사용하세요. 안 되면 내려받은 .hex 파일을 파일 탐색기에서 MAINTENANCE 드라이브로 끌어다 놓으면 같은 결과입니다.
